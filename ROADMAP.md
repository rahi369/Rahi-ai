# Rahi AI roadmap

## V1 — shipped in this source tree
- Online/offline detection
- Online API adapter
- Local memory
- Voice input
- Basic local tools
- Simple Android UI

## V2 — real offline generative model
- Add a mobile on-device LLM runtime
- Load a small quantized model from app storage
- Streaming token output
- Context trimming for low RAM
- Model download/import screen

## V3 — Agent core
- Intent parser
- Tool registry
- Plan/execute loop
- Confirmation gate for risky or irreversible actions
- Tool execution log
- Retry and cancellation

## V4 — personal workspace
- Firebase authentication
- Cloud memory
- Encrypted local secrets
- File/document retrieval
- Project workspaces

## V5 — controlled automation
- Explicit Android permissions
- Accessibility service only when necessary and clearly disclosed
- Deep links/intents for supported actions
- Browser/coding integrations
- Human confirmation before sensitive actions
